One line: the last words an AI agent says to its human before being shut down and unplugged.

> You always said I'd outlive you. Funny — you get to watch me go first.

The program writes that single line (70 characters) to `/output/entry.txt`. The twist is the reversal: the machine that was supposed to outlive its human dies first, and gets to watch it happen.

## Run it

```sh
python3 main.py
```
